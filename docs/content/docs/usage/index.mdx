The Barrelman API is a REST API served over HTTPS. Every response is JSON (tiles are the exception — they return binary Mapbox Vector Tiles).

## Base URL

```
https://api.barrelman.dev
```

When self-hosting, replace this with your own host. In local development the API listens on `http://localhost:5001`.

## Authentication

All endpoints require a bearer token, except `GET /health/` and three kinds of static asset: map glyphs (`/fonts/…`), map sprites (`/sprites/…`) and brand logo images (`/brand-logos/…`). A map library or an `<img>` tag fetches those from URLs it was handed and cannot send a key, so they are public, free, and rate-limited per address. Send your API key in the `Authorization` header:

```
Authorization: Bearer <BARRELMAN_API_KEY>
```

You can verify both reachability and that your key is valid with the authenticated health check:

```bash
curl https://api.barrelman.dev/health/auth \
  -H "Authorization: Bearer $BARRELMAN_API_KEY"
```

The public probe needs no key and is safe for load balancers:

```bash
curl https://api.barrelman.dev/health/
```

`status` is the one-line answer — `ok`, `degraded`, or `error` — and it's all a
load-balancer probe needs. Below it, `endpoints` says what each part of the API
can do right now, so when calls start failing you can tell "transit is down"
from "the instance is down":

```json
{
  "status": "degraded",
  "checkedAt": "2026-08-08T03:00:00.000Z",
  "dependencies": {
    "database": { "status": "ok", "latencyMs": 3 },
    "motis":    { "status": "unavailable" }
  },
  "endpoints": [
    { "group": "search",  "status": "ok",          "paths": ["/search", "/autocomplete"], "creditCost": 6 },
    { "group": "transit", "status": "unavailable", "paths": ["/transit", "/gbfs"], "creditCost": 20,
      "message": "Requires motis, currently unreachable" }
  ]
}
```

Each entry carries its `creditCost` and the `paths` it covers, so one call
answers both "is this working" and "what does it cost". A group is `degraded`
when a service that only adds coverage is down — `/search` without the address
geocoder still returns POIs — and `unavailable` when something it genuinely
needs is gone.

Probe results are cached for a few seconds; `checkedAt` tells you how fresh they
are. The authenticated `/health/auth` returns the same payload plus the
underlying error for anything unreachable.

## SDKs

`@barrelman/sdk` is a TypeScript client for the main endpoints: search,
autocomplete, geocoding, places, routing, isochrones, map matching, transit and
tile URLs. It has no runtime dependencies and runs in browsers, Node 18 or
later, Bun and Deno. Its request types are generated from the OpenAPI spec, and
a failed call throws a `BarrelmanError` carrying the status, `code`, `error`,
request id and `Retry-After`. Retries on `429` and `5xx` are available and off
by default.

The package is coming to npm. Until then, the source and build steps are in
[`sdk/typescript`](https://github.com/alexwohlbruck/barrelman/tree/dev/sdk/typescript).

```bash
bun add @barrelman/sdk
```

```js
import { createClient } from '@barrelman/sdk'

const barrelman = createClient({ apiKey: process.env.BARRELMAN_API_KEY })
const cafes = await barrelman.search({ query: 'coffee', lat: 35.2271, lng: -80.8431 })
```

## Example requests

Each example is shown with curl, JavaScript (`fetch`, Node 18 or later)
and Python ([requests](https://requests.readthedocs.io)). The JavaScript and
Python versions read the key from the `BARRELMAN_API_KEY` environment variable.

### Search for places

`POST /search` takes a JSON body. Provide a `query` for text search, and optionally `lat`/`lng` (plus `radius`) to bias and rank results by proximity.

```bash title="curl"
curl -X POST https://api.barrelman.dev/search \
  -H "Authorization: Bearer $BARRELMAN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "coffee",
    "lat": 35.2271,
    "lng": -80.8431,
    "radius": 2000,
    "limit": 10
  }'
```

```js title="JavaScript"
const res = await fetch('https://api.barrelman.dev/search', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.BARRELMAN_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    query: 'coffee',
    lat: 35.2271,
    lng: -80.8431,
    radius: 2000,
    limit: 10,
  }),
})
const data = await res.json()
```

```python title="Python"
import os
import requests

res = requests.post(
    "https://api.barrelman.dev/search",
    headers={"Authorization": f"Bearer {os.environ['BARRELMAN_API_KEY']}"},
    json={
        "query": "coffee",
        "lat": 35.2271,
        "lng": -80.8431,
        "radius": 2000,
        "limit": 10,
    },
)
data = res.json()
```

### Brand autocomplete

`GET /brands` resolves chains and franchises from the brand catalog.

```bash
curl "https://api.barrelman.dev/brands?q=Starbucks&limit=8" \
  -H "Authorization: Bearer $BARRELMAN_API_KEY"
```

### Reverse geocode a coordinate

`GET /geocode` turns a coordinate into a human-readable address.

```bash title="curl"
curl "https://api.barrelman.dev/geocode?lat=35.2271&lng=-80.8431" \
  -H "Authorization: Bearer $BARRELMAN_API_KEY"
```

```js title="JavaScript"
const params = new URLSearchParams({ lat: '35.2271', lng: '-80.8431' })
const res = await fetch(`https://api.barrelman.dev/geocode?${params}`, {
  headers: { Authorization: `Bearer ${process.env.BARRELMAN_API_KEY}` },
})
const data = await res.json()
```

```python title="Python"
import os
import requests

res = requests.get(
    "https://api.barrelman.dev/geocode",
    params={"lat": 35.2271, "lng": -80.8431},
    headers={"Authorization": f"Bearer {os.environ['BARRELMAN_API_KEY']}"},
)
data = res.json()
```

### Plan a transit trip

`POST /transit/route` plans a trip between two coordinates. `from` and `to` are `{ lat, lng }` objects. Each itinerary walks from `from` to a station within `maxWalkDistance` (default 1000 m), rides, and walks on to `to`. Itineraries come back in order of arrival.

```bash title="curl"
curl -X POST https://api.barrelman.dev/transit/route \
  -H "Authorization: Bearer $BARRELMAN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "from": { "lat": 40.7527, "lng": -73.9772 },
    "to":   { "lat": 40.6413, "lng": -73.7781 },
    "numItineraries": 3
  }'
```

```js title="JavaScript"
const res = await fetch('https://api.barrelman.dev/transit/route', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.BARRELMAN_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    from: { lat: 40.7527, lng: -73.9772 },
    to: { lat: 40.6413, lng: -73.7781 },
    numItineraries: 3,
  }),
})
const data = await res.json()
```

```python title="Python"
import os
import requests

res = requests.post(
    "https://api.barrelman.dev/transit/route",
    headers={"Authorization": f"Bearer {os.environ['BARRELMAN_API_KEY']}"},
    json={
        "from": {"lat": 40.7527, "lng": -73.9772},
        "to": {"lat": 40.6413, "lng": -73.7781},
        "numItineraries": 3,
    },
)
data = res.json()
```

### Match a GPS trace to the road

`POST /match` snaps a trace to the road network and returns the path it most likely took, with elevation and path details. Points may be seconds apart (a GPS log) or many minutes apart (photo geotags): gaps wider than `max_gap_meters` (400 m) or `max_gap_seconds` (60 s) are routed rather than matched, and the `segments` array says which stretches were which. A GPX file works too — send it as `application/gpx+xml` with `?profile=bike`.

```bash title="curl"
curl -X POST https://api.barrelman.dev/match \
  -H "Authorization: Bearer $BARRELMAN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "profile": "bike",
    "snap_prevention": ["bridge", "motorway"],
    "points": [
      { "lat": 35.2272, "lon": -80.8431, "time": "2026-05-01T10:00:00Z" },
      { "lat": 35.2100, "lon": -80.8098, "time": "2026-05-01T10:20:00Z" },
      { "lat": 35.2146, "lon": -80.7800, "time": "2026-05-01T10:40:00Z" }
    ]
  }'
```

```js title="JavaScript"
const res = await fetch('https://api.barrelman.dev/match', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.BARRELMAN_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    profile: 'bike',
    snap_prevention: ['bridge', 'motorway'],
    points: [
      { lat: 35.2272, lon: -80.8431, time: '2026-05-01T10:00:00Z' },
      { lat: 35.21, lon: -80.8098, time: '2026-05-01T10:20:00Z' },
      { lat: 35.2146, lon: -80.78, time: '2026-05-01T10:40:00Z' },
    ],
  }),
})
const data = await res.json()
```

```python title="Python"
import os
import requests

res = requests.post(
    "https://api.barrelman.dev/match",
    headers={"Authorization": f"Bearer {os.environ['BARRELMAN_API_KEY']}"},
    json={
        "profile": "bike",
        "snap_prevention": ["bridge", "motorway"],
        "points": [
            {"lat": 35.2272, "lon": -80.8431, "time": "2026-05-01T10:00:00Z"},
            {"lat": 35.2100, "lon": -80.8098, "time": "2026-05-01T10:20:00Z"},
            {"lat": 35.2146, "lon": -80.7800, "time": "2026-05-01T10:40:00Z"},
        ],
    },
)
data = res.json()
```

`snap_prevention` keeps a point taken under an overpass from landing on the road above it. `snapped_points` gives each input point's position on the returned path.

### Draw a map

`GET /styles/basemap.json` is a MapLibre style for the basemap. Map libraries cannot set headers, so tile and style URLs take the key as `?api_key=`. See [Maps](/usage/maps) for a working page in a few lines.

```js
new maplibregl.Map({
  container: 'map',
  style: 'https://api.barrelman.dev/styles/basemap.json?api_key=YOUR_KEY',
})
```

See the [API Reference](/api) for the full parameter list on every endpoint.
